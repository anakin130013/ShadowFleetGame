Before you start

  1. Use Chrome or Edge on a computer (Windows, Mac, Linux or a Chromebook).
  2. Plug the Waveshare ESP32-S3-Touch-AMOLED-1.43 into the computer with a USB-C cable that carries data.
  3. Close the Arduino IDE or anything else that might be using the board's port.
This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer. The page must be opened over https to install. FIRMWARE v1.0

Installing

  1. Click Install and pick the board's port from the list (often "USB JTAG/serial debug unit").
  2. First install: choose to erase the device. Updating: don't erase, and your saved Wi-Fi stays.
  3. Wait for it to finish (about a minute). The screen restarts into the Shadow Fleet lobby.

If the port doesn't show up

  1. Try another cable: many USB-C cables only carry power.
  2. Hold BOOT, press and release RESET, release BOOT, then click Install again.
