# Favor bank (draft v2, 2026-10-19) -- replaces late_favors.txt and the 3 fixed
# favors per faction. Each conversation that ends in a favor DRAWS 3 at random
# (user: only 12 favors would get memorized). Every favor is something the game
# can judge itself.
#
# N = a normal favor (3 rounds). Those marked * are the faction's HARD favors:
#     with two or more misses ONE of them is drawn at random and is the only offer
#     (v0.30.4, playtest 2026-10-28: "it was the same every time" -- there used to be
#     one per faction). Hard = take a rival world, destroy a fleet, a Core world, hold two.
# L = a LATE favor (the last 2 rounds). A late draw = 1 CREDITS + 2 deeds.
#     CREDITS = paid on the spot; {cr} = your PAY price for this planet x 1.5
#     (at least +4) -- always more than buying it outright, so a missed late
#     negotiation is a gamble that costs you. Late deeds are due when the war
#     ends; the screen says how many rounds that is. Undone = the faction takes
#     the planet back (and its VP) before the final count.
#
# Checks (the game judges them):
#   TAKE <f>      gain a planet of faction f        WIN_PVP     destroy another commander's fleet
#   NO_INVEST     no defense investment here        NO_ATTACK <f> attack no planet of faction f
#   HOLD          still hold this planet at the end TRIBUTE <n> pay n Credits at every round start
#   WIN_BATTLE    NEW: win any battle               TAKE_CORE   NEW: gain a Core world
#   HOLD_TWO <f>  NEW: hold this planet and a world of faction f (always the RIVAL) at the same time
#   CREDITS       late only: pay {cr} now
#   WIN_BATTLE = capture a planet in a fight, or destroy another commander's fleet.
#
# Format:  N|L <R|E|P|C> | [*]<CHECK> [arg] | text
#          H <R|E|P|C> | line    (a hostile faction unmasking itself at the end of a
#                                 conversation, or refusing to talk -- v0.30.1)
